# v1.0.5 检查记录

检查范围：上传与取消、95% 磁盘保护、文件生命周期、永久分享、账号与权限、历史分页、单文件和 ZIP 下载、HEAD / Range 续传、普通和加密 ZIP 预览、桌面与移动布局、Docker 安装和更新恢复。

修复的问题：

- 登录 / 注册 / 密码接口缺失请求正文时返回 500；请求解析错误和磁盘错误提示可能暴露内部信息。
- 无效退出登录重写账号库；设置 HTTPS 分享域名后，HTTP 管理入口错误地设置 Secure Cookie。
- 历史分页可接受非整数、无穷大或越界页；删除与新下载存在短暂竞争。
- 关闭 ZIP、文本、图片或 PDF 预览后，旧请求可能改写新窗口；令牌过期提示与 Blob 释放不完整。
- 重复升级请求可能并行查版本；Docker stop / rename 已完成但 HTTP 响应超时后，原容器可能未恢复。
- 版本服务临时故障没有重试；文件名中的点目录与 Unicode 处理不完整；临时 JSON 写入失败残留文件。
- 无终端安装和密码重置错误判断 `/dev/tty`；更新过程中密码重置存在冲突风险。
- 配置刷新后的保留时间说明、默认选项、历史重载与连续上传状态不一致。

验证：33 项 Node 测试覆盖正常流程和故障注入；Playwright 覆盖注册、登录、修改密码、上传、复制、直链、图片 / 文本 / 加密 ZIP 预览和下载、迟到响应、永久分享、历史、设置、明暗主题及多种桌面 / 手机尺寸。构建核对源码、部署文件和版本一致性；依赖扫描未发现已知漏洞。

GitHub Actions 另验证实际 Docker 启动、磁盘保护、账号初始化 / 重置、升级和失败回滚。服务器检查仅记录健康状态、容量、日志和文件完整性；功能验证使用隔离临时目录或本次创建的临时文件。

这些检查覆盖当前版本已实现的功能与已复现问题，不表示能证明不存在所有未知缺陷。Office 文档、浏览器不支持的媒体编码和超出在线 ZIP 预览大小 / 时限的内容仍需本地下载查看。
